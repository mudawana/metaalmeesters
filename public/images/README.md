# Originele foto's van MetaalMeesters

De foto's van https://metaalmeesters.eu/ worden door de GitHub Actions-importer in deze map opgeslagen.
Ook lokaal mogelijk met `npm run download:images`.

Bestanden: Metaalmeesters_Home_01.jpg, _02.jpg, _03.jpg, _04.jpg,
Metaalmeesters_Home_2_450x338.jpg en deuren.jpg t/m deuren4.jpg.

Alle rechten bij de oorspronkelijke rechthebbenden. Gebruik voor de klantwebsite na bevestiging van de klant.
De front-end heeft een fallback naar de originele URL's als een lokaal bestand ontbreekt.
