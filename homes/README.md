De foto's worden alleen gebruikt als voorbeeldachtergrond om een configuratie te visualiseren.
Klant kan ook zelf een woningfoto uploaden.

**Belangrijke beperkingen:**
- Dit zijn echte foto's van woningen en geen 3D-huisrenders. Het betreft stockfotografie.
- De fotograaf of eigenaar van de afgebeelde woning onderschrijft MetaalMeesters niet.
- Er is geen toestemming verleend om iemand op deze foto's voor te stellen als klant.
- Voor foto's waarop al een deur staat kan de configurator die bestaande deur momenteel
  niet echt verwijderen; er wordt een 3D-deur over de originele ingang geplaatst.
- Dit is een visuele indicatie van de vormgeving, geen bouwkundig nauwkeurige montage.
- Vermijd overname op een stockfoto-platform of verkoop van de onbewerkte bronfoto.
- Beelden en tekst vallen onder de Pexels-licentie; bij latere wijzigingen van bronnen
  moet de licentie van het exacte gekozen beeld opnieuw gecontroleerd worden.

Deze bestanden worden in `public/homes/` opgeslagen door
`scripts/download-house-images.mjs` en GitHub Actions `import-house-images.yml`.
