# MetaalMeesters — website & 3D-deurenconfigurator

React/Vite demo met interactieve 3D-deuren, maatvoering, materialen, indeling en offerteaanvraag.

## Lokaal starten

```bash
npm install
npm run dev
```

Bekijk `docs/VRAGEN_AAN_METAALMEESTERS.txt` voor de open vragen.

**Demo:** voor het automatisch versturen van aanvragen is later een server of e-mailprovider nodig. De demo bereidt een complete aanvraag voor met een e-mailconcept en downloadbaar configuratiebestand.
